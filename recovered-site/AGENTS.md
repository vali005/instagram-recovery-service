# OpenCode instructions

This directory is the canonical Recovery website. Work only from this source
for new product, design, content, accessibility, SEO, and conversion tasks.

Before opening a pull request, run:

1. `npm ci`
2. `npm run lint`
3. `npm test`

Never request or store passwords, SMS codes, backup codes, identity documents,
API keys, or tokens. Never change GitHub Actions, repository permissions,
domains, payments, secrets, or deployment ownership without explicit owner
approval. Preserve truthful claims and avoid guaranteed recovery promises.

Create changes in a separate branch and open a pull request. Do not publish or
merge directly.
